# korda-labs

Marketing site for **Korda Labs** (kordalabs.com) and its product **Keel** — one app for tasks & calendars, powered by AI that does them. **Zoe** is the otter who skippers the AI crew.

- Next.js static export (`output: 'export'`) → Cloudflare Pages (`out/`).
- `npm run dev` · `npm run build` · `npm run deploy`
- Brand rules for this repo: `.claude/DESIGN/DESIGN_PRINCIPLES.md`
- Brand assets: `public/brand` (logos), `public/zoe` (Zoe poses)
